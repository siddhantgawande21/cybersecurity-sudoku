# Cybersecurity Sudoku: The Threat Matrix

Cybersecurity Sudoku: The Threat Matrix is an educational web-based game that combines the classic Sudoku puzzle with cybersecurity awareness questions.

Players answer cybersecurity questions to unlock Sudoku cells, earn points, and learn about common cyber threats while solving puzzles.

## Features

- Interactive 9×9 Sudoku puzzle
- Cybersecurity multiple-choice questions
- Five progressive difficulty levels
- Score system
- Guest mode with no login required
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Cybersecurity Topics

- Phishing
- Smishing
- Vishing
- Ransomware
- Man-in-the-Middle (MITM)
- Distributed Denial of Service (DDoS)
- SQL Injection
- Account Compromise

## Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into `C:\xampp\htdocs\`.
4. Create the `cybersecurity_sudoku` database in phpMyAdmin.
5. Import the provided database schema and ensure the required game data is available.
6. Configure the database credentials in `config/database.php`.
7. Open the following URL in your browser:

   `http://localhost/cybersecurity-sudoku/`

## Project Purpose

The goal of this project is to make cybersecurity education more interactive and engaging through puzzle-solving and quiz-based learning.
